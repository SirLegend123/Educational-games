🔥 Matchstick Patterns

Each pattern is made from matchsticks and grows by the same amount every time, so it makes a linear sequence. Predict the next patterns, find the nth term, and discover why the rule works.

How to play

  • There are 4 patterns, with 4 questions each: pattern 4, pattern 10, the nth term, and which pattern uses a given number of matchsticks.
  • Press 🎨 Show how it grows to colour the matchsticks. You'll see the sticks every pattern starts with, and the block each new step adds.
  • Right first time earns a ⭐. A wrong answer gets a hint, and a second wrong answer shows the working.
