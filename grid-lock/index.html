🔒 Grid Lock

Twelve locks, each sealed with a pair of brackets. Expand them with the grid method to break free!

The grid method: (x + 3)(x + 5)

×x+5
x
+3
  • Step 1: multiply each term on the left by each term on the top. Keep the signs: +3 × −5 = −15.
  • Step 2: add up all four boxes and collect the like terms (the two x terms): x² + 5x + 3x + 15 = x² + 8x + 15.
  • Watch out for squares: (x + 4)² means (x + 4)(x + 4), so the answer is x² + 8x + 16, not x² + 16!
  • Use the on-screen keypad: tap a box, then type. It has a ² key, so x² is just x then ². (You can also type x^2.)

Each lock is worth 🔑🔑: one for the grid right first time, and one for the final answer right first time. A wrong answer gets a hint, and a second wrong answer shows the working.
