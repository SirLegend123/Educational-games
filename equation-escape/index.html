🚪 Equation Escape Room

You're locked in! Each door has an equation on it, and the answer is the code that unlocks it. Solve all ten to escape. The equations get harder as you go.

How it works

  • Type the value of x and press Unlock. Fractions like 7/2 and negatives like −3 are fine.
  • Get it right within two tries to collect a 🔑 key. After one wrong try you'll get a hint. After two, you'll see the full working.
  • The rooms go: one-step equations → two-step → brackets → unknowns on both sides → fractions → the final boss.
  • The clock is ticking ⏱️. Can you escape with all 10 keys?
