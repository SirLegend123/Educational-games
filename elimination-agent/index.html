🕵️ Elimination Agent

HQ has intercepted pairs of coded clues. Each pair hides two secret numbers, x and y. Crack all ten codes by solving the simultaneous equations with the elimination method.

Agent training: the elimination method

  1. Match: multiply one or both equations so the x terms, or the y terms, are the same size.
  2. Eliminate: if the matching terms have the same sign, subtract the equations. If they have different signs, add them. That letter disappears!
  3. Solve the equation that's left to find one letter.
  4. Substitute it back into one of the original equations to find the other letter.
  5. Check both values work in the other equation.

Each step right first time earns a 🗝️ (up to 4 per code). A wrong answer gets a hint, and a second wrong answer shows the working.
