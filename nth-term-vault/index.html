🔐 Nth Term Vault

Ten safes stand between you and the treasure. Each safe shows a linear sequence. Crack the first lock by finding the nth term, then use your rule to open the second lock.

Finding the nth term

  1. Find the difference between terms. For 7, 11, 15, 19… it's +4, so the rule starts 4n (the 4 times table: 4, 8, 12, 16…).
  2. Compare the sequence with 4n: 7 is 3 more than 4, 11 is 3 more than 8… so the nth term is 4n + 3.
  3. Check: when n = 2, 4 × 2 + 3 = 11 ✓

Type rules like 4n + 3, 5n − 2 or 20 − 3n. Opening a lock first time earns a 🔑. A wrong answer gets a hint, and a second wrong answer shows the working.
